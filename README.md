# Employee Attrition Analysis Skill

This project provides a starter structure for HR analytics focused on predicting employee attrition risk. The goal is to help HR and business stakeholders identify turnover patterns, understand key drivers of attrition, and support proactive retention strategies through data validation, feature engineering, modeling, and reporting workflows.

## Setup

```bash
pip install -r requirements.txt
```

## How to Run

```bash
python scripts/validate_data.py --input data/employee-attrition.csv
```

## Dataset Source

IBM HR Analytics dataset from Kaggle (public domain).

## Folder Structure Overview

- `SKILL.md`: Skill definition placeholder.
- `REFERENCE.md`: Reference guide placeholder.
- `data/`: Dataset and data dictionary.
- `scripts/`: Placeholder scripts for validation, feature engineering, modeling, and reporting.
- `templates/`: HTML report template placeholder.
- `outputs/`: Generated artifacts folder (`.gitkeep` included).
- `requirements.txt`: Python package dependencies.
